# My Web Portfolio

A professional, responsive portfolio website built to showcase my skills and projects. 
This site features a sleek dark theme and is fully optimized for mobile and desktop viewing.

## 🛠️ Built With

- **HTML5 & CSS3** - Core structure and custom styling.

- **JavaScript** - Interactive elements and functionality.

- **Bootstrap 5** - Used for responsive layout, typography, and specialized components.

- **GitHub Pages** - Hosting and continuous deployment.



## ✨ Key Features

- **Responsive Design:** Seamlessly transitions between mobile, tablet, and desktop screens.

- **Dark Theme:** A modern, high-contrast dark aesthetic for better readability and style.

- **Cumulative Build:** Developed section-by-section to ensure clean, scalable code.



## 📂 Project Structure

The project is organized into dedicated pages for better navigation and maintainability:

- **Root Files**
  - `index.html`          # Homepage & Landing area
  - `about.html`          # Detailed professional background
  - `skills.html`         # Technical proficiencies & tools
  - `resume.html`         # Experience and education history
  - `portfolio.html`      # Gallery of completed projects
  - `contact.html`        # Contact form and social links

- **Assets Directory** (`/assets`)
  - `/css`                # Custom styles and Bootstrap overrides
  - `/js`                 # Interactive elements and scripts
  - `/img`                # Photos, icons, and project screenshots
  - `/vendor`             # Third-party libraries (Bootstrap, Icons, etc.)

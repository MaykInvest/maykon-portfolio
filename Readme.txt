📂 Project Structure

The project is organized into dedicated pages for better navigation and maintainability:

Root Files

```
index.html        # Homepage & Landing area
about.html        # Professional background
skills.html       # Technical skills & tools
resume.html       # Experience and education
portfolio.html    # Project showcase
contact.html      # Contact form and links
```

Assets Directory (`/assets`)

```
/css              # Custom styles and overrides
/js               # Scripts and interactivity
/img              # Images and assets
/vendor           # Third-party libraries (Bootstrap, Icons, etc.)
```
